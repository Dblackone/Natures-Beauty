This design system is the single source of truth for all visual decisions made for Nature's Beauty Construction's digital presence. All tokens are defined in tokens.css and should be consumed via CSS custom properties — never hardcode colour hex values or spacing pixels directly in component styles.

Colors

The palette is built on three brand colour families — Gold (primary), Forest Green (secondary), and Earth Brown (neutral) — each with a full 100–900 scale. Semantic tokens map these scales to roles like surface, text, and status.

Shadows & Elevation

Six elevation levels plus two brand-coloured glows. Use elevation to communicate hierarchy — higher shadow = more prominence.

--shadow-sm Subtle lift. Dividers, inline elements.
--shadow-md Default card shadow.
--shadow-lg Hover state, dropdowns.
--shadow-xl Modals, featured cards.
--shadow-gold Primary button hover, gold CTA.
--shadow-green Secondary button hover, landscape accents.

CSS Variables Reference

All tokens are defined in tokens.css. Import it at the top of any stylesheet.

/* Import design tokens */ @import './tokens.css'; /* Use tokens in your components */ .my-component { background: var(--color-surface); color: var(--color-text-primary); padding: var(--space-5) var(--space-6); border-radius: var(--radius-lg); box-shadow: var(--shadow-md); font-family: var(--font-body); font-size: var(--text-base); transition: all var(--transition-base); }
